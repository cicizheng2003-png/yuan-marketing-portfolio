Yuan Zheng Marketing Portfolio — V4

Files:
- index.html  -> page structure and copy
- styles.css  -> styling and layout
- script.js   -> interactive case panel content
- assets/     -> image assets used on the site
- docs/       -> supporting PDF for Cygnus / VEGA
- video/      -> embedded editing sample

Quick edits:
1. Open index.html in a browser to preview the site.
2. Edit project text in script.js.
3. Replace images in assets/ and update the file paths in script.js if needed.
4. Replace the video file in video/ if you want to swap the editing sample.
